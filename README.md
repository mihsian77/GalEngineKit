# GalEngineKit

> galgame / 视觉小说引擎适配与中文化工具箱

**定位**：面向 galgame 与视觉小说的引擎适配、字体修复与中文化工具集。核心是"引擎档案库（数据）+ 通用钩子启动器 + 插件化钩子 DLL + 容器配置助手"四层架构，全部独立实现，针对 ARM 翻译运行环境做钩子策略优化。

## 特性

- **引擎档案库**：JSON 格式的引擎适配档案，覆盖识别签名、文本渲染路径、字体方案、钩子目标、容器配置建议；社区可只贡献数据不写代码
- **通用钩子启动器**：配置驱动的进程注入启动器，支持多 DLL 组合注入、可选静态字节补丁、简易 GUI
- **插件化钩子 DLL**：ini 驱动、x86/x64 分离、严格限定钩子目标在游戏自身代码（主动避开模拟器内置 API 的脆弱点）
- **容器配置助手**：一键写入字体注册表替换、DLL override、容器环境变量
- **数据工具集**：引擎封包解包/解密/编辑/重打包（按引擎逐步扩展）

## 架构

```
┌─────────────────────────────────────────────────┐
│  数据层  引擎档案库（JSON）                        │
│          识别签名 / 渲染路径 / 字体方案 / 容器建议  │
├─────────────────────────────────────────────────┤
│  工具层  通用钩子启动器 · 容器配置助手 · 数据工具集  │
├─────────────────────────────────────────────────┤
│  钩子层  插件化钩子 DLL 框架                       │
│          ini 驱动 · x86/x64 · 只钩游戏自身代码      │
├─────────────────────────────────────────────────┤
│  环境层  Windows / Wine + 动态二进制翻译运行环境     │
└─────────────────────────────────────────────────┘
```

## 快速开始

```bash
# 校验引擎档案
python3 tools/validate_profile.py profiles/*.json

# 查看档案列表
ls profiles/
```
